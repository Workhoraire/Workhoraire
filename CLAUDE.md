# WorkHoraire

## Instructions

The project instructions are defined in `AGENTS.md`.

Always read and follow `AGENTS.md` before making any changes to the project.

`AGENTS.md` is the source of truth for:
- Project architecture
- Technical stack
- Coding conventions
- Security rules
- Multi-tenancy rules
- Development workflow
- Testing requirements
- Infrastructure decisions

Do not duplicate or override the rules defined in `AGENTS.md`.

When working on the project:
1. Read `AGENTS.md`.
2. Inspect the existing code before making changes.
3. Follow the architecture and conventions defined there.
4. Prefer simple solutions and avoid unnecessary complexity.
5. Run relevant tests and checks after making changes.

If a request conflicts with `AGENTS.md`, ask for clarification before proceeding.
